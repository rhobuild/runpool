## runpool gc

Collect cache lanes and finished lease records (dry run by default)

```
runpool gc [flags]
```

### Options

```
      --aggressive   plan every free lane, not just expired and over-budget ones
      --apply        perform the evictions (default is a dry run)
  -h, --help         help for gc
```
